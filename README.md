## Why C?

C is a great language for understanding data structures in depth, because it gives you direct control over memory. Here we work with fundamental structures such as vectors, matrices, stacks, queues and graphs.

Like athletes training their bodies, programmers train their minds, and mastering data structures and algorithms (DSA) is essential for programming competitions.

## How to Use This Repository

Grab your laptop or desktop, and a notebook to write down your questions and insights. Then open your terminal and clone the repository.

**Using HTTPS:**

```bash
git clone https://github.com/Dom-Henrique/ds-c.git
```

**Using SSH** (requires an [SSH key](https://docs.github.com/en/authentication/connecting-to-github-with-ssh) linked to your GitHub account):

```bash
git clone git@github.com:Dom-Henrique/ds-c.git
```

And voilà! 🎉

Happy coding, and good luck with your studies!
